# Collect Raw Sync History Requirements

> 상태: 승인됨
>
> 승인: 2026-08-02 사용자 명시 승인
>
> Hermes projection 보완: 2026-08-02 사용자 명시 요구

## 목적

`collect-raw-sync-history`는 사용자가 지정한 날짜 구간에 `raw`에
동기화된 작업 목록을 모아 조회한다.

## 배치와 소유권

1. 이 기능의 정본은 Mnemosyne 저장소가 소유한다.
2. 이 기능은 `/Users/pureliture/raw` 디렉터리에서만 사용하는 전용
   스킬로 배치한다.
3. Codex 호환 raw projection을 정본에서 생성하고, Hermes는 같은 raw
   projection을 external skill root로 조회한다. Hermes 사용자 전역에 이
   스킬의 사본을 만들지 않는다.
4. 이 기능은 조회만 수행하며 저장된 기억이나 외부 대상을 변경하지
   않는다.

## 필수 동작

1. 사용자가 지정한 날짜 구간에 포함되는 동기화 작업을 조회한다.
2. 한 번의 sync에 여러 작업이 포함되어 있으면 각 작업을 별도 목록
   항목으로 반환한다.
3. 각 작업 항목에 해당 sync의 기록 시각과 출처를 함께 표시한다.
4. 완전히 동일한 작업 기록이 반복된 경우에만 하나로 정리한다.

## 범위 밖

- 현재 프로젝트의 개발 맥락 탐색
- 현재 코드 확인과 구현 사실 판정
- 조회 결과를 이용한 후속 변경 작업

## 완료 조건

1. 지정한 날짜 구간의 동기화 작업이 사람이 읽을 수 있는 목록으로
   반환된다.
2. 각 작업에서 sync 기록 시각과 출처를 확인할 수 있다.
3. 완전히 동일한 작업 기록만 중복 없이 정리된다.
4. 조회 과정에서 저장된 기억이나 외부 대상이 변경되지 않는다.
5. Codex와 Hermes가 읽는 `SKILL.md`는 같은 Mnemosyne 정본에서 생성되며,
   Hermes용 별도 동작 사본을 두지 않는다.
