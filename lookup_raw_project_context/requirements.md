# Lookup Raw Project Context Requirements

> 상태: 승인됨
>
> 승인: 2026-08-02 사용자 명시 승인
>
> Hermes projection 보완: 2026-08-02 사용자 명시 요구

## 목적

`lookup-raw-project-context`는 현재 프로젝트, 작업 맥락, 사용자 질문을
바탕으로 관련 `raw` 맥락을 먼저 조회하고 그 맥락을 이용한 현재 코드
탐색을 지원한다.

## 배치와 소유권

1. 이 기능의 정본은 Mnemosyne 저장소가 소유한다.
2. 이 기능은 프로젝트 디렉터리에 관계없이 사용할 수 있는 유저레벨
   스킬로 배치한다.
3. Codex와 Hermes 사용자 레벨 projection은 같은 Mnemosyne 정본에서
   생성한다.
4. 이 기능은 `raw`와 현재 프로젝트를 읽기만 하며 어느 쪽도 변경하지
   않는다.

## 필수 동작

1. 현재 프로젝트와 작업 맥락에서 확인할 수 있는 정보를 사용자에게
   다시 묻지 않고 조회에 사용한다.
2. 사용자 질문과 현재 프로젝트·작업 맥락을 함께 사용해 관련 `raw`
   맥락을 찾는다.
3. 현재 프로젝트를 식별할 근거가 부족하거나 동등한 `raw` 후보가 여러
   개이면 임의로 하나를 선택하지 않고 후보 또는 부족한 근거를 알린다.
4. 관련 `raw` 맥락이 없거나 조회할 수 없으면 그 결과와 사유를 알리고
   현재 코드 탐색을 계속한다.
5. 현재 코드를 살펴보기 전에 확인된 관련 `raw` 맥락을 먼저 읽는다.
6. 조회한 `raw` 맥락의 출처를 사용자가 확인할 수 있게 표시한다.
7. 조회한 맥락을 길잡이로 현재 코드를 살펴본다.
8. `raw` 맥락과 현재 코드가 다르면 현재 구현 사실은 코드를 기준으로
   판단하고 그 불일치를 사용자에게 알린다.
9. 불일치가 답변의 판단에 영향을 주면 답변 상단에 짧게 알리고 상세
   근거에서 `raw` 맥락과 코드 기준을 구분한다.

## 범위 밖

- 날짜 구간에 동기화된 작업 목록 집계
- `raw` 기억의 동기화 또는 변경
- 현재 프로젝트 코드의 변경
- 조회 결과를 이용한 후속 변경 작업

## 완료 조건

1. 조회 결과로 관련 `raw` 맥락, 관련 맥락 없음, 조회 불가, 또는 프로젝트
   식별 모호성 중 하나가 명확히 표시된다.
2. 관련 맥락이 조회되면 그 출처를 확인할 수 있다.
3. 현재 코드를 살펴봐야 하는 질문에서는 `raw` 조회 결과를 먼저 확인한
   뒤 코드를 확인한다.
4. 관련 맥락이 없거나 조회할 수 없거나 프로젝트 식별이 모호해도 그
   사실을 알린 뒤 현재 코드 탐색을 계속한다.
5. `raw` 맥락과 현재 코드가 다르면 불일치가 표시되고 현재 구현 사실은
   코드 기준으로 설명된다.
6. 조회 과정에서 `raw`나 현재 프로젝트가 변경되지 않는다.
7. Codex와 Hermes에 설치된 `SKILL.md`가 동일한 정본과 일치한다.
